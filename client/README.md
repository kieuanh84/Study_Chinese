# Frontend

React/Vite frontend cho Study Chinese.

## Chạy dev

```bash
npm install
npm run dev
```

## Cấu hình

Tạo `client/.env`:

```env
VITE_GOOGLE_CLIENT_ID=your-google-oauth-client-id.apps.googleusercontent.com
VITE_API_URL=http://localhost:3000/api
```

## Scripts

```bash
npm run lint
npm run build
```
